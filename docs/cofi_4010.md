# **COFI 4010 — Balancete**

Envio (→ CVM) do Balancete no padrão **COFI 4010**: arquivo texto de largura fixa, extensão
`.cvm`, registros de 71 posições
([`PadraoCOFI.aspx`](https://cvmweb.cvm.gov.br/SWB/Sistemas/SCW/PadroesXML/PadraoCOFI.aspx),
compartilhado com o COFI 4016). A página `PadraoXMLBalancete.asp` não define XML.

> **Veja também:** [Referência da API](api/index.md)

## Descrição

Monte um `Cofi4010Document` (de 1 a N `Cofi4010Fund`, todos da mesma competência, cada um com
suas `Cofi4010Account`) e serialize com `Cofi4010().export(doc, output_path=None)`. Com
`output_path` o arquivo é gravado de forma atômica em ASCII e o retorno é `None`.

| Registro | Conteúdo (posições) |
|---|---|
| Cabeçalho | `#C1` (1-3), código do documento `4010` (4-7), CNPJ (8-21), filler (22-29), competência `MMAAAA` (30-35), filler (36-71) |
| Conta | conta com DV (1-10), filler (11-14), total (15-32) + sinal (33), até 90 dias (34-51) + sinal (52), após 90 dias (53-70) + sinal (71) |
| Rodapé | `@1` (1-2), registros gravados incluindo cabeçalhos e o próprio rodapé (3-8), filler (9-71) |

O sinal é `-` para valor negativo e branco para positivo (a página aceita `+` ou branco).

## Decisões

- A página não declara a escala decimal dos valores de 18 posições. O writer assume 2 casas
  (valor absoluto em centavos, truncado, nunca arredondado); `float` é aceito apenas via
  conversão para `Decimal` por string.
- A página não define o terminador de linha. O writer emite `\r\n`.
- O CNPJ do fundo é validado pelos dígitos verificadores.

## Não são verificados

- O dígito verificador da conta: só se exige 10 dígitos.
- Se a conta existe no plano de contas do Balancete.
- Coerência entre as colunas (total versus até 90 dias mais após 90 dias).
- Competência igual entre os fundos do mesmo arquivo.
- A codificação EBCDIC (a página cita `7B`/`7C` apenas como equivalentes dos marcadores).
